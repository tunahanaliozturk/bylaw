# Backlog

One file per roadmap feature. Each item has an id, a size and what "done" means, so anyone can pick one up and everyone can see where it stands.

- **Sizes:** S is about a day, M two to four days, L a week or more.
- **Working on an item:** mention its id in the pull request title or body (`INC-2: ...`). Tick the box in the same pull request that finishes it.
- **New ideas:** open an issue first; once it is agreed, it gets an id in the right file.
