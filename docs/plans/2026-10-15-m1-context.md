# M1: context without a model, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `bylaw context` turns a GitHub pull request or a local branch into a `ReviewContext` JSON (changed lines, rule sources, requirements with acceptance criteria, deterministic `.editorconfig` findings) without calling any model.

**Architecture:** A `RepoSource` protocol with two implementations (GitHub API, local git) feeds pure functions: a diff parser, an `.editorconfig` resolver and checker, a rule collector and a requirement collector. `build_context` composes them and the CLI prints the result. Rules and `.bylaw.toml` are read from the base commit, specs from the head commit.

**Tech Stack:** Python 3.15 (supports 3.13+), uv, hatchling, pydantic 2.14.1, httpx 0.28.1; pytest 9.1.1, respx 0.23.1, ruff 0.17.0, mypy 2.4.0 strict.

**Spec:** `docs/design.md`, ADRs in `docs/adr/`, milestone in `docs/ROADMAP.md` (M1).

## Global Constraints

- `.python-version` is `3.15`; `requires-python = ">=3.13"`; CI tests on 3.13 and 3.15, on Ubuntu and Windows.
- Runtime dependencies: `pydantic>=2.14.1`, `httpx>=0.28.1`, nothing else. Dev: `pytest>=9.1.1`, `pytest-cov>=7.1.0`, `respx>=0.23.1`, `ruff>=0.17.0`, `mypy>=2.4.0`. Build: `hatchling>=1.32.4`.
- No model calls anywhere in M1. No network in unit tests; GitHub is mocked with respx.
- Rule sources and `.bylaw.toml` are read from the base commit; spec files from the head commit (ADR 0004).
- bylaw never executes pull request code. `git` runs with an argument list, never `shell=True`.
- The GitHub token never appears in output, errors or logs.
- Repository text is decoded as UTF-8 with `errors="replace"`; one bad byte must not abort a review.
- Docs and comments in English, British spelling, no em dashes.
- Commits: conventional commit messages, authored by the owner only, no co-author trailer, no AI attribution.
- Formatting: when `ruff format --check` fails on new code, run `uv run ruff format .` and re-check; the plan's code is not pre-wrapped to the line limit.
- Quality gates: `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy src tests`, `uv run pytest`, `uv run python tools/license_audit.py`.

## Review Focus

1. A patch line ending in `\r` (CRLF file): trailing whitespace and line length checks must ignore the `\r`, and only the `end_of_line = lf` rule reports it. Test in Task 4.
2. A base file that is not valid UTF-8 (a Latin-1 `CONTRIBUTING.md`): decoded with replacement characters, no crash. Test in Task 5.
3. A pull request with more than 100 changed files: every page of `/pulls/{n}/files` is read. Test in Task 6.
4. A PR body linking `../../secret.md`, an `http` URL or a spec in another repository: none of them is read. Test in Task 8.
5. Non-ASCII content printed on a Windows console using cp1252: the CLI writes UTF-8 bytes and does not raise `UnicodeEncodeError`. Test in Task 10.

"""The contract between bylaw's parts and the hosts that run it. Everything here serialises to JSON."""

from enum import StrEnum
from typing import Literal

from pydantic import BaseModel, ConfigDict


class Category(StrEnum):
    SECURITY = "security"
    BUG = "bug"
    RULE = "rule"
    REQUIREMENT = "requirement"


class Severity(StrEnum):
    CRITICAL = "critical"
    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"
    SUGGESTION = "suggestion"


class RuleKind(StrEnum):
    EDITORCONFIG = "editorconfig"
    LINTER = "linter"
    PROSE = "prose"


FileStatus = Literal["added", "modified", "renamed", "removed"]


class _Frozen(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")


class AddedLine(_Frozen):
    number: int
    text: str


class ChangedFile(_Frozen):
    path: str
    status: FileStatus
    previous_path: str | None = None
    added_lines: tuple[AddedLine, ...] = ()
    missing_final_newline: bool = False
    patch_omitted: bool = False


class RuleSource(_Frozen):
    path: str
    kind: RuleKind
    text: str


class Criterion(_Frozen):
    key: str
    text: str


class Requirement(_Frozen):
    source: str
    title: str
    text: str
    criteria: tuple[Criterion, ...]


class Finding(_Frozen):
    file: str
    line_start: int
    line_end: int
    category: Category
    severity: Severity
    message: str
    suggestion: str | None = None
    evidence: str | None = None


class ReviewContext(_Frozen):
    base_sha: str
    head_sha: str
    title: str
    files: tuple[ChangedFile, ...]
    rules: tuple[RuleSource, ...]
    requirements: tuple[Requirement, ...]
    findings: tuple[Finding, ...]
    notes: tuple[str, ...]
```

`src/bylaw/diff.py`:

```python
"""Parses unified diffs into the lines a pull request adds, numbered as they appear in the new file."""

import re

from bylaw.model import AddedLine, ChangedFile, FileStatus

_HUNK = re.compile(r"^@@ -\d+(?:,\d+)? \+(\d+)(?:,\d+)? @@")
_GIT_HEADER = re.compile(r"^a/(?P<old>.+) b/(?P<new>.+)$")


def parse_patch(patch: str) -> tuple[tuple[AddedLine, ...], bool]:
    """Return the added lines and whether the new file ends without a newline.

    Lines are split on "\\n" only, so a "\\r" from a CRLF file stays in the text for the end_of_line check.
    """
    added: list[AddedLine] = []
    new_line = 0
    last_was_added = False
    missing_newline = False
    for raw in patch.split("\n"):
        if hunk := _HUNK.match(raw):
            new_line = int(hunk.group(1))
            last_was_added = False
        elif raw.startswith("\\"):
            # "\ No newline at end of file" describes the line just above it.
            missing_newline = missing_newline or last_was_added
        elif raw.startswith("+"):
            added.append(AddedLine(number=new_line, text=raw[1:]))
            new_line += 1
            last_was_added = True
        elif raw.startswith("-"):
            last_was_added = False
        else:
            new_line += 1
            last_was_added = False
    return tuple(added), missing_newline


def parse_unified_diff(text: str) -> tuple[ChangedFile, ...]:
    """Parse `git diff` output. Binary files and mode-only changes have no added lines."""
    files: list[ChangedFile] = []
    for block in re.split(r"(?m)^diff --git ", text)[1:]:
        header, marker, body = block.partition("\n@@")
        lines = header.split("\n")
        status: FileStatus = "modified"
        old_path: str | None = None
        new_path: str | None = None
        binary = False
        if names := _GIT_HEADER.match(lines[0]):
            old_path, new_path = names["old"], names["new"]
        for line in lines[1:]:
            if line.startswith("new file mode"):
                status = "added"
            elif line.startswith("deleted file mode"):
                status = "removed"
            elif line.startswith("rename from "):
                old_path = line.removeprefix("rename from ")
                status = "renamed"
            elif line.startswith("rename to "):
                new_path = line.removeprefix("rename to ")
            elif line.startswith("--- a/"):
                old_path = line.removeprefix("--- a/")
            elif line.startswith("+++ b/"):
                new_path = line.removeprefix("+++ b/")
            elif line.startswith("Binary files"):
                binary = True
        path = old_path if status == "removed" else new_path
        if path is None:
            continue
        added, missing = parse_patch("@@" + body) if marker else ((), False)
        files.append(
            ChangedFile(
                path=path,
                status=status,
                previous_path=old_path if status == "renamed" else None,
                added_lines=added,
                missing_final_newline=missing,
                patch_omitted=binary,
            )
        )
    return tuple(files)
```

`src/bylaw/editorconfig.py`:

```python
"""Resolves .editorconfig properties for a path, following https://spec.editorconfig.org.

Files are read through a callback so the same code works on the base branch via the GitHub API and on a
local repository. Each property remembers the file and line that set it, which becomes the evidence on a
finding.
"""

import re
from collections.abc import Callable
from dataclasses import dataclass
from pathlib import PurePosixPath
from typing import Self

_KNOWN = frozenset(
    {
        "indent_style",
        "indent_size",
        "tab_width",
        "end_of_line",
        "charset",
        "trim_trailing_whitespace",
        "insert_final_newline",
        "max_line_length",
        "root",
    }
)
_RANGE = re.compile(r"([+-]?\d+)\.\.([+-]?\d+)")


@dataclass(frozen=True, slots=True)
class Property:
    value: str
    source: str
    line: int


@dataclass(frozen=True, slots=True)
class _Section:
    pattern: re.Pattern[str]
    ranges: tuple[tuple[int, int], ...]
    properties: tuple[tuple[str, str, int], ...]

    @classmethod
    def from_glob(cls, glob: str, properties: tuple[tuple[str, str, int], ...]) -> Self:
        anchored = "/" in glob
        regex, ranges = _translate(glob.removeprefix("/"))
        if not anchored:
            regex = f"(?:.*/)?{regex}"
        return cls(re.compile(regex), tuple(ranges), properties)

    def matches(self, relative_path: str) -> bool:
        match = self.pattern.fullmatch(relative_path)
        if match is None:
            return False
        return all(
            value is None or low <= int(value) <= high
            for (low, high), value in zip(self.ranges, match.groups(), strict=True)
        )


@dataclass(frozen=True, slots=True)
class _File:
    path: str
    directory: str
    text: str
    root: bool
    sections: tuple[_Section, ...]


class EditorConfigResolver:
    def __init__(self, read: Callable[[str], str | None]) -> None:
        self._read = read
        self._cache: dict[str, _File | None] = {}

    @property
    def files_read(self) -> tuple[tuple[str, str], ...]:
        return tuple((f.path, f.text) for f in self._cache.values() if f is not None)

    def properties(self, path: str) -> dict[str, Property]:
        chain: list[_File] = []
        for directory in _directories(path):
            config = self._load(directory)
            if config is None:
                continue
            chain.append(config)
            if config.root:
                break
        result: dict[str, Property] = {}
        for config in reversed(chain):
            relative = path[len(config.directory) + 1 :] if config.directory else path
            for section in config.sections:
                if section.matches(relative):
                    for key, value, line in section.properties:
                        result[key] = Property(value, config.path, line)
        return result

    def _load(self, directory: str) -> _File | None:
        if directory not in self._cache:
            path = f"{directory}/.editorconfig" if directory else ".editorconfig"
            text = self._read(path)
            self._cache[directory] = None if text is None else _parse(path, directory, text)
        return self._cache[directory]


def _directories(path: str) -> list[str]:
    return ["" if str(parent) == "." else str(parent) for parent in PurePosixPath(path).parents]


def _parse(path: str, directory: str, text: str) -> _File:
    root = False
    raw: list[tuple[str, list[tuple[str, str, int]]]] = []
    for number, line in enumerate(text.splitlines(), start=1):
        stripped = line.strip()
        if not stripped or stripped[0] in "#;":
            continue
        if stripped.startswith("[") and stripped.endswith("]"):
            raw.append((stripped[1:-1], []))
            continue
        key, separator, value = stripped.partition("=")
        if not separator:
            continue
        key, value = key.strip().lower(), value.strip()
        if key in _KNOWN:
            value = value.lower()
        if raw:
            raw[-1][1].append((key, value, number))
        elif key == "root":
            root = value == "true"
    sections = tuple(_Section.from_glob(glob, tuple(properties)) for glob, properties in raw)
    return _File(path=path, directory=directory, text=text, root=root, sections=sections)


def _translate(glob: str) -> tuple[str, list[tuple[int, int]]]:  # noqa: PLR0912 - one branch per glob token
    out: list[str] = []
    ranges: list[tuple[int, int]] = []
    i = 0
    while i < len(glob):
        char = glob[i]
        i += 1
        if char == "\\" and i < len(glob):
            out.append(re.escape(glob[i]))
            i += 1
        elif char == "*":
            if glob.startswith("*", i):
                out.append(".*")
                i += 1
            else:
                out.append("[^/]*")
        elif char == "?":
            out.append("[^/]")
        elif char == "[":
            end = glob.find("]", i)
            body = glob[i:end] if end != -1 else ""
            if not body or "/" in body:
                out.append(re.escape("["))
            else:
                i = end + 1
                negated = body.startswith("!")
                body = body.removeprefix("!").replace("\\", "\\\\").replace("[", "\\[").replace("^", "\\^")
                out.append(f"[^/{body}]" if negated else f"[{body}]")
        elif char == "{":
            end = _closing_brace(glob, i - 1)
            if end == -1:
                out.append(re.escape("{"))
                continue
            inner = glob[i:end]
            i = end + 1
            alternatives = _split_alternatives(inner)
            if numbers := _RANGE.fullmatch(inner):
                ranges.append((int(numbers[1]), int(numbers[2])))
                out.append(r"([+-]?\d+)")
            elif len(alternatives) > 1:
                parts: list[str] = []
                for alternative in alternatives:
                    regex, inner_ranges = _translate(alternative)
                    parts.append(regex)
                    ranges.extend(inner_ranges)
                out.append(f"(?:{'|'.join(parts)})")
            else:
                out.append(re.escape(f"{{{inner}}}"))
        else:
            out.append(re.escape(char))
    return "".join(out), ranges


def _closing_brace(glob: str, start: int) -> int:
    depth = 0
    i = start
    while i < len(glob):
        char = glob[i]
        if char == "\\":
            i += 2
            continue
        if char == "{":
            depth += 1
        elif char == "}":
            depth -= 1
            if depth == 0:
                return i
        i += 1
    return -1


def _split_alternatives(body: str) -> list[str]:
    parts: list[str] = []
    current: list[str] = []
    depth = 0
    i = 0
    while i < len(body):
        char = body[i]
        if char == "\\" and i + 1 < len(body):
            current.append(body[i : i + 2])
            i += 2
            continue
        if char == "{":
            depth += 1
        elif char == "}":
            depth -= 1
        elif char == "," and depth == 0:
            parts.append("".join(current))
            current = []
            i += 1
            continue
        current.append(char)
        i += 1
    parts.append("".join(current))
    return parts
```

"""Checks added lines against .editorconfig without a model. These findings are exact and cost nothing."""

from collections.abc import Mapping

from bylaw.editorconfig import Property
from bylaw.model import Category, ChangedFile, Finding, Severity

_DEFAULT_INDENT = 4


def check(file: ChangedFile, properties: Mapping[str, Property]) -> tuple[Finding, ...]:
    if file.status == "removed" or file.patch_omitted or not file.added_lines:
        return ()
    lines = [(a.number, a.text.removesuffix("\r"), a.text.endswith("\r")) for a in file.added_lines]
    rules: list[tuple[str, list[int], str]] = []

    style = properties.get("indent_style")
    if style is not None and style.value == "space":
        tabbed = [n for n, text, _ in lines if "\t" in _indent(text)]
        rules.append(("indent_style", tabbed, "Indented with tabs where .editorconfig asks for spaces"))
    elif style is not None and style.value == "tab":
        spaces = " " * _indent_width(properties)
        spaced = [n for n, text, _ in lines if _indent(text).startswith(spaces)]
        rules.append(("indent_style", spaced, "Indented with spaces where .editorconfig asks for tabs"))

    if _is_true(properties, "trim_trailing_whitespace"):
        trailing = [n for n, text, _ in lines if text != text.rstrip(" \t")]
        rules.append(("trim_trailing_whitespace", trailing, "Trailing whitespace"))

    limit = properties.get("max_line_length")
    if limit is not None and limit.value.isdigit():
        long_lines = [n for n, text, _ in lines if len(text) > int(limit.value)]
        rules.append(("max_line_length", long_lines, f"Longer than {limit.value} characters"))

    # ponytail: only `lf` is checked. Repositories usually store LF and convert to CRLF on checkout, so a
    # `crlf` rule would flag every stored line. Revisit if a user stores CRLF on purpose.
    eol = properties.get("end_of_line")
    if eol is not None and eol.value == "lf":
        crlf = [n for n, _, has_cr in lines if has_cr]
        rules.append(("end_of_line", crlf, "CRLF line ending where .editorconfig asks for LF"))

    findings = [_finding(file.path, properties[name], numbers, text) for name, numbers, text in rules if numbers]
    if file.missing_final_newline and _is_true(properties, "insert_final_newline"):
        last = file.added_lines[-1].number
        findings.append(
            _finding(file.path, properties["insert_final_newline"], [last], "No newline at the end of the file")
        )
    return tuple(findings)


def _indent(text: str) -> str:
    return text[: len(text) - len(text.lstrip(" \t"))]


def _indent_width(properties: Mapping[str, Property]) -> int:
    for key in ("indent_size", "tab_width"):
        value = properties.get(key)
        if value is not None and value.value.isdigit():
            return int(value.value)
    return _DEFAULT_INDENT


def _is_true(properties: Mapping[str, Property], key: str) -> bool:
    value = properties.get(key)
    return value is not None and value.value == "true"


def _finding(path: str, prop: Property, numbers: list[int], text: str) -> Finding:
    first = numbers[0]
    where = f"on line {first}" if len(numbers) == 1 else f"on {len(numbers)} added lines, first at line {first}"
    return Finding(
        file=path,
        line_start=first,
        line_end=first,
        category=Category.RULE,
        severity=Severity.LOW,
        message=f"{text} {where}.",
        evidence=f"{prop.source}:{prop.line}",
    )
```

"""Where a review's input comes from. GitHub and local git implement the same protocol."""

from dataclasses import dataclass
from typing import Protocol

from bylaw.model import ChangedFile


class SourceError(Exception):
    """The change could not be read. The message is safe to print."""


@dataclass(frozen=True, slots=True)
class ChangeInfo:
    base_sha: str
    head_sha: str
    title: str
    body: str
    commit_messages: tuple[str, ...]


@dataclass(frozen=True, slots=True)
class IssueRef:
    owner: str
    repo: str
    number: int

    def label(self, default_repo: str | None) -> str:
        full = f"{self.owner}/{self.repo}"
        if default_repo is not None and full == default_repo.lower():
            return f"issue#{self.number}"
        return f"{full}#{self.number}"


@dataclass(frozen=True, slots=True)
class Issue:
    ref: IssueRef
    title: str
    body: str


class RepoSource(Protocol):
    @property
    def repo(self) -> str | None: ...

    def info(self) -> ChangeInfo: ...

    def changed_files(self) -> tuple[ChangedFile, ...]: ...

    def read_base(self, path: str) -> str | None: ...

    def read_head(self, path: str) -> str | None: ...

    def closing_issue_refs(self) -> tuple[IssueRef, ...]: ...

    def read_issue(self, ref: IssueRef) -> Issue | None: ...

```python
"""Reads a change from a local repository, for reviewing a branch before a pull request exists."""

import subprocess
from pathlib import Path

from bylaw.diff import parse_unified_diff
from bylaw.model import ChangedFile
from bylaw.source import ChangeInfo, Issue, IssueRef, SourceError


class LocalGitSource:
    """Committed changes from merge-base(base, HEAD) to HEAD. Uncommitted work is not included."""

    def __init__(self, repo_dir: Path, base: str, repo: str | None = None) -> None:
        self._dir = repo_dir
        self._repo = repo.lower() if repo else None
        self._head = self._git("rev-parse", "HEAD").strip()
        self._base = self._git("merge-base", base, self._head).strip()

    @property
    def repo(self) -> str | None:
        return self._repo

    def info(self) -> ChangeInfo:
        log = self._git("log", "--format=%B%x00", f"{self._base}..{self._head}")
        messages = tuple(message.strip() for message in log.split("\0") if message.strip())
        return ChangeInfo(self._base, self._head, title="", body="", commit_messages=messages)

    def changed_files(self) -> tuple[ChangedFile, ...]:
        diff = self._git("-c", "core.quotePath=false", "diff", "--no-color", "--no-ext-diff", "-M", self._base, self._head)
        return parse_unified_diff(diff)

    def read_base(self, path: str) -> str | None:
        return self._show(self._base, path)

    def read_head(self, path: str) -> str | None:
        return self._show(self._head, path)

    def closing_issue_refs(self) -> tuple[IssueRef, ...]:
        return ()

    def read_issue(self, ref: IssueRef) -> Issue | None:  # noqa: ARG002 - local mode has no issue API
        return None

    def _show(self, revision: str, path: str) -> str | None:
        result = self._run("show", f"{revision}:{path}")
        return result.stdout.decode("utf-8", errors="replace") if result.returncode == 0 else None

    def _git(self, *args: str) -> str:
        result = self._run(*args)
        if result.returncode != 0:
            message = result.stderr.decode("utf-8", errors="replace").strip()
            raise SourceError(f"git {' '.join(args)} failed: {message}")
        return result.stdout.decode("utf-8", errors="replace")

    def _run(self, *args: str) -> subprocess.CompletedProcess[bytes]:
        # git is resolved from PATH on purpose; arguments are a list, so nothing goes through a shell.
        return subprocess.run(["git", *args], cwd=self._dir, capture_output=True, check=False)  # noqa: S603, S607
```

```python
"""Reads a pull request through the GitHub REST and GraphQL APIs."""

from collections.abc import Mapping
from functools import cached_property
from http import HTTPStatus
from typing import Self
from urllib.parse import quote

import httpx
from pydantic import BaseModel, ConfigDict, Field, TypeAdapter

from bylaw.diff import parse_patch
from bylaw.model import ChangedFile, FileStatus
from bylaw.source import ChangeInfo, Issue, IssueRef

_PAGE_SIZE = 100
_MAX_FILE_PAGES = 30  # GitHub lists at most 3000 files for a pull request.
_MAX_COMMIT_PAGES = 3  # and at most 250 commits.
_STATUS: dict[str, FileStatus] = {"added": "added", "removed": "removed", "renamed": "renamed"}
_CLOSING_QUERY = """
query($owner: String!, $name: String!, $number: Int!) {
  repository(owner: $owner, name: $name) {
    pullRequest(number: $number) {
      closingIssuesReferences(first: 25) { nodes { number repository { nameWithOwner } } }
    }
  }
}
"""

Params = Mapping[str, str | int]


class GitHubError(Exception):
    """A GitHub API call failed. The message never contains the token."""


class _Model(BaseModel):
    model_config = ConfigDict(frozen=True, extra="ignore")


class _Ref(_Model):
    sha: str


class PullRequest(_Model):
    title: str
    body: str | None = None
    base: _Ref
    head: _Ref


class PullFile(_Model):
    filename: str
    status: str
    previous_filename: str | None = None
    patch: str | None = None


class _CommitDetail(_Model):
    message: str


class _Commit(_Model):
    commit: _CommitDetail


class _IssueResponse(_Model):
    title: str
    body: str | None = None
    pull_request: dict[str, object] | None = None


class _GqlRepo(_Model):
    name_with_owner: str = Field(alias="nameWithOwner")


class _GqlIssue(_Model):
    number: int
    repository: _GqlRepo


class _GqlConnection(_Model):
    nodes: list[_GqlIssue]


class _GqlPull(_Model):
    closing: _GqlConnection = Field(alias="closingIssuesReferences")


class _GqlRepository(_Model):
    pull_request: _GqlPull | None = Field(default=None, alias="pullRequest")


class _GqlData(_Model):
    repository: _GqlRepository | None = None


class _GqlResponse(_Model):
    data: _GqlData | None = None
    errors: list[dict[str, object]] | None = None


_PULL_FILES = TypeAdapter(list[PullFile])
_COMMITS = TypeAdapter(list[_Commit])


class GitHubClient:
    def __init__(self, token: str, api_url: str = "https://api.github.com", graphql_url: str | None = None) -> None:
        self._api_url = api_url.rstrip("/")
        self._graphql_url = graphql_url or f"{self._api_url}/graphql"
        self._http = httpx.Client(
            headers={
                "Authorization": f"Bearer {token}",
                "Accept": "application/vnd.github+json",
                "X-GitHub-Api-Version": "2022-11-28",
                "User-Agent": "bylaw",
            },
            timeout=30.0,
        )

    def __enter__(self) -> Self:
        return self

    def __exit__(self, *exc_info: object) -> None:
        self._http.close()

    def pull(self, repo: str, number: int) -> PullRequest:
        return PullRequest.model_validate(self._get(f"/repos/{repo}/pulls/{number}").json())

    def pull_files(self, repo: str, number: int) -> list[PullFile]:
        files: list[PullFile] = []
        for page in range(1, _MAX_FILE_PAGES + 1):
            params = {"per_page": _PAGE_SIZE, "page": page}
            batch = _PULL_FILES.validate_python(self._get(f"/repos/{repo}/pulls/{number}/files", params).json())
            files.extend(batch)
            if len(batch) < _PAGE_SIZE:
                break
        return files

    def pull_commit_messages(self, repo: str, number: int) -> list[str]:
        messages: list[str] = []
        for page in range(1, _MAX_COMMIT_PAGES + 1):
            params = {"per_page": _PAGE_SIZE, "page": page}
            batch = _COMMITS.validate_python(self._get(f"/repos/{repo}/pulls/{number}/commits", params).json())
            messages.extend(item.commit.message for item in batch)
            if len(batch) < _PAGE_SIZE:
                break
        return messages

    def file_text(self, repo: str, path: str, ref: str) -> str | None:
        response = self._get_optional(
            f"/repos/{repo}/contents/{quote(path)}", {"ref": ref}, accept="application/vnd.github.raw+json"
        )
        return None if response is None else response.content.decode("utf-8", errors="replace")

    def issue(self, ref: IssueRef) -> Issue | None:
        response = self._get_optional(f"/repos/{ref.owner}/{ref.repo}/issues/{ref.number}")
        if response is None:
            return None
        data = _IssueResponse.model_validate(response.json())
        if data.pull_request is not None:
            return None
        return Issue(ref=ref, title=data.title, body=data.body or "")

    def closing_issue_refs(self, repo: str, number: int) -> tuple[IssueRef, ...]:
        owner, _, name = repo.partition("/")
        variables = {"owner": owner, "name": name, "number": number}
        response = self._send("POST", self._graphql_url, json={"query": _CLOSING_QUERY, "variables": variables})
        _raise_for_status(response)
        payload = _GqlResponse.model_validate(response.json())
        if payload.errors:
            raise GitHubError(f"GitHub GraphQL query for closing issues failed: {payload.errors[0].get('message')}")
        repository = payload.data.repository if payload.data else None
        pull = repository.pull_request if repository else None
        if pull is None:
            return ()
        refs: list[IssueRef] = []
        for node in pull.closing.nodes:
            ref_owner, _, ref_name = node.repository.name_with_owner.lower().partition("/")
            refs.append(IssueRef(ref_owner, ref_name, node.number))
        return tuple(refs)

    def _get(self, path: str, params: Params | None = None) -> httpx.Response:
        response = self._send("GET", f"{self._api_url}{path}", params=params)
        _raise_for_status(response)
        return response

    def _get_optional(self, path: str, params: Params | None = None, accept: str | None = None) -> httpx.Response | None:
        response = self._send("GET", f"{self._api_url}{path}", params=params, accept=accept)
        if response.status_code == HTTPStatus.NOT_FOUND:
            return None
        _raise_for_status(response)
        return response

    def _send(
        self,
        method: str,
        url: str,
        *,
        params: Params | None = None,
        accept: str | None = None,
        json: object = None,
    ) -> httpx.Response:
        headers = {"Accept": accept} if accept else None
        try:
            return self._http.request(method, url, params=params, headers=headers, json=json)
        except httpx.HTTPError as error:
            raise GitHubError(f"Could not reach GitHub at {url}: {type(error).__name__}") from error


def _raise_for_status(response: httpx.Response) -> None:
    if response.is_success:
        return
    try:
        body = response.json()
    except ValueError:
        body = None
    message = str(body.get("message", "")) if isinstance(body, dict) else ""
    if response.headers.get("x-ratelimit-remaining") == "0":
        reset = response.headers.get("x-ratelimit-reset", "unknown")
        message = f"rate limit exceeded, resets at Unix time {reset}"
    request = response.request
    raise GitHubError(f"GitHub returned {response.status_code} for {request.method} {request.url.path}: {message}")


class GitHubSource:
    def __init__(self, client: GitHubClient, repo: str, number: int) -> None:
        self._client = client
        self._repo = repo.lower()
        self._number = number

    @property
    def repo(self) -> str:
        return self._repo

    @cached_property
    def _pull(self) -> PullRequest:
        return self._client.pull(self._repo, self._number)

    def info(self) -> ChangeInfo:
        messages = tuple(self._client.pull_commit_messages(self._repo, self._number))
        pull = self._pull
        return ChangeInfo(pull.base.sha, pull.head.sha, pull.title, pull.body or "", messages)

    def changed_files(self) -> tuple[ChangedFile, ...]:
        files: list[ChangedFile] = []
        for item in self._client.pull_files(self._repo, self._number):
            added, missing = parse_patch(item.patch) if item.patch is not None else ((), False)
            files.append(
                ChangedFile(
                    path=item.filename,
                    status=_STATUS.get(item.status, "modified"),
                    previous_path=item.previous_filename if item.status == "renamed" else None,
                    added_lines=added,
                    missing_final_newline=missing,
                    patch_omitted=item.patch is None,
                )
            )
        return tuple(files)

    def read_base(self, path: str) -> str | None:
        return self._client.file_text(self._repo, path, self._pull.base.sha)

    def read_head(self, path: str) -> str | None:
        return self._client.file_text(self._repo, path, self._pull.head.sha)

    def closing_issue_refs(self) -> tuple[IssueRef, ...]:
        return self._client.closing_issue_refs(self._repo, self._number)

    def read_issue(self, ref: IssueRef) -> Issue | None:
        return self._client.issue(ref)
```

"""Collects the repository's written rules from the base branch (ADR 0004)."""

from collections.abc import Callable, Sequence
from pathlib import PurePosixPath

from bylaw.model import ChangedFile, RuleKind, RuleSource

PROSE_FILES = (
    "CONTRIBUTING.md",
    ".github/CONTRIBUTING.md",
    "docs/CONTRIBUTING.md",
    "AGENTS.md",
    "CLAUDE.md",
    ".github/copilot-instructions.md",
    "STYLEGUIDE.md",
)

_JAVASCRIPT = (
    "eslint.config.js",
    "eslint.config.mjs",
    "eslint.config.cjs",
    "eslint.config.ts",
    ".eslintrc.json",
    ".eslintrc.js",
    ".eslintrc.cjs",
    ".eslintrc.yml",
    ".eslintrc.yaml",
    ".prettierrc",
    ".prettierrc.json",
)

# ponytail: only configuration at the repository root is read. Nested configs (a monorepo package with its
# own ruff.toml) are a later addition.
LINTER_FILES: dict[str, tuple[str, ...]] = {
    ".py": ("ruff.toml", ".ruff.toml", "pyproject.toml"),
    **dict.fromkeys((".js", ".jsx", ".mjs", ".cjs", ".ts", ".tsx", ".vue"), _JAVASCRIPT),
    ".go": (".golangci.yml", ".golangci.yaml"),
    ".cs": (".globalconfig", "Directory.Build.props"),
    ".rb": (".rubocop.yml",),
}

# pyproject.toml is left out: most edits to it are not rule changes, and the note would be noise.
RULE_PATHS = frozenset(
    {*PROSE_FILES, *(path for paths in LINTER_FILES.values() for path in paths), ".bylaw.toml"}
) - {"pyproject.toml"}


def collect_rules(
    changed: Sequence[ChangedFile],
    read_base: Callable[[str], str | None],
    editorconfig_files: Sequence[tuple[str, str]],
) -> tuple[RuleSource, ...]:
    sources = [RuleSource(path=path, kind=RuleKind.EDITORCONFIG, text=text) for path, text in editorconfig_files]
    suffixes = sorted({PurePosixPath(f.path).suffix for f in changed if f.status != "removed"})
    linter_paths = dict.fromkeys(path for suffix in suffixes for path in LINTER_FILES.get(suffix, ()))
    for path in linter_paths:
        text = read_base(path)
        if text is None or (path == "pyproject.toml" and "[tool.ruff" not in text):
            continue
        sources.append(RuleSource(path=path, kind=RuleKind.LINTER, text=text))
    for path in PROSE_FILES:
        text = read_base(path)
        if text is not None:
            sources.append(RuleSource(path=path, kind=RuleKind.PROSE, text=text))
    return tuple(sources)
```

```python
"""Finds the requirements a change claims to implement and extracts their acceptance criteria (ADR 0003)."""

import re
from collections.abc import Iterable, Sequence
from pathlib import PurePosixPath
from urllib.parse import unquote

from bylaw.model import ChangedFile, Criterion, Requirement
from bylaw.source import ChangeInfo, IssueRef, RepoSource

_ISSUE_REF = re.compile(
    r"\b(?:close[sd]?|fix(?:e[sd])?|resolve[sd]?):?\s+"
    r"(?:https://github\.com/(?P<url_repo>[\w.-]+/[\w.-]+)/issues/|(?P<repo>[\w.-]+/[\w.-]+)?#)"
    r"(?P<number>\d+)\b",
    re.IGNORECASE,
)
_MD_LINK = re.compile(r"\]\((?P<target>[^)\s]+?\.md)(?:#[^)\s]*)?\)")
_BLOB_URL = re.compile(r"https://github\.com/(?P<repo>[\w.-]+/[\w.-]+)/blob/[^/\s]+/(?P<path>[^)\s#]+?\.md)\b")

_TASK = re.compile(r"^\s*[-*+]\s+\[[ xX]\]\s+(?P<text>\S.*)$")
_HEADING = re.compile(r"^(?P<hashes>#{1,6})\s+(?P<title>.+?)\s*#*\s*$")
_LIST_ITEM = re.compile(r"^\s*(?:[-*+]|\d+[.)])\s+(?:\[[ xX]\]\s+)?(?P<text>\S.*)$")
_CRITERIA_HEADING = re.compile(r"acceptance criteria|requirements|kabul kriterleri", re.IGNORECASE)
_GHERKIN_START = re.compile(r"^\s*(?:[-*+]\s+)?(?:\*\*)?given\b", re.IGNORECASE)
_GHERKIN_NEXT = re.compile(r"^\s*(?:[-*+]\s+)?(?:\*\*)?(?:when|then|and|but)\b", re.IGNORECASE)


def parse_issue_refs(texts: Iterable[str], default_repo: str | None) -> tuple[IssueRef, ...]:
    refs: list[IssueRef] = []
    for text in texts:
        for match in _ISSUE_REF.finditer(text):
            full = match["url_repo"] or match["repo"] or default_repo
            if full is None:
                continue
            owner, _, name = full.lower().partition("/")
            refs.append(IssueRef(owner, name, int(match["number"])))
    return tuple(dict.fromkeys(refs))


def spec_paths(changed: Sequence[ChangedFile], body: str, globs: Sequence[str], repo: str | None) -> tuple[str, ...]:
    candidates = [
        f.path
        for f in changed
        if f.status != "removed"
        and f.path.endswith(".md")
        and any(PurePosixPath(f.path).full_match(g) for g in globs)
    ]
    for match in _BLOB_URL.finditer(body):
        if repo is not None and match["repo"].lower() == repo.lower():
            candidates.append(unquote(match["path"]))
    candidates.extend(m["target"] for m in _MD_LINK.finditer(body) if "://" not in m["target"])
    normalised = (_normalise(path) for path in candidates)
    return tuple(dict.fromkeys(path for path in normalised if path is not None))


def extract_criteria(markdown: str) -> tuple[Criterion, ...]:  # noqa: PLR0912 - one branch per markdown shape
    texts: list[str] = []
    in_fence = False
    criteria_level: int | None = None
    gherkin: list[str] | None = None
    for line in markdown.splitlines():
        if line.lstrip().startswith(("```", "~~~")):
            in_fence = not in_fence
            continue
        if in_fence:
            continue
        if gherkin is not None:
            if _GHERKIN_NEXT.match(line):
                gherkin.append(_clean(line))
                continue
            texts.append(" ".join(gherkin))
            gherkin = None
        if heading := _HEADING.match(line):
            level = len(heading["hashes"])
            if criteria_level is not None and level <= criteria_level:
                criteria_level = None
            if _CRITERIA_HEADING.search(heading["title"]):
                criteria_level = level
        elif _GHERKIN_START.match(line):
            gherkin = [_clean(line)]
        elif task := _TASK.match(line):
            texts.append(task["text"].strip())
        elif criteria_level is not None and (item := _LIST_ITEM.match(line)):
            texts.append(item["text"].strip())
    if gherkin:
        texts.append(" ".join(gherkin))
    unique = dict.fromkeys(texts)
    return tuple(Criterion(key=f"AC-{i}", text=text) for i, text in enumerate(unique, start=1))


def collect_requirements(
    source: RepoSource,
    info: ChangeInfo,
    changed: Sequence[ChangedFile],
    spec_globs: Sequence[str],
) -> tuple[tuple[Requirement, ...], tuple[str, ...]]:
    requirements: list[Requirement] = []
    notes: list[str] = []
    keyword_refs = parse_issue_refs([info.body, *info.commit_messages], source.repo)
    for ref in dict.fromkeys([*source.closing_issue_refs(), *keyword_refs]):
        label = ref.label(source.repo)
        issue = source.read_issue(ref)
        if issue is None:
            notes.append(f"Could not read {label}; it is left out of the requirement check.")
            continue
        requirements.append(_requirement(label, issue.title, issue.body))
    for path in spec_paths(changed, info.body, spec_globs, source.repo):
        text = source.read_head(path)
        if text is None:
            notes.append(f"Linked spec {path} does not exist at the head commit.")
            continue
        requirements.append(_requirement(path, _title(text, path), text))
    notes.extend(f"{r.source} has no structured acceptance criteria." for r in requirements if not r.criteria)
    return tuple(requirements), tuple(notes)


def _requirement(source: str, title: str, text: str) -> Requirement:
    return Requirement(source=source, title=title, text=text, criteria=extract_criteria(text))


def _title(markdown: str, fallback: str) -> str:
    for line in markdown.splitlines():
        if heading := _HEADING.match(line):
            return heading["title"]
    return fallback


def _clean(line: str) -> str:
    return line.strip().lstrip("-*+ ").replace("**", "").strip()


def _normalise(path: str) -> str | None:
    parts = PurePosixPath(path.lstrip("/")).parts
    if not parts or ".." in parts:
        return None
    return "/".join(parts)
```

"""Optional .bylaw.toml, always read from the base branch so a change cannot loosen its own review."""

import tomllib

from pydantic import BaseModel, ConfigDict, ValidationError


class ConfigError(Exception):
    """The configuration file is invalid. The message is safe to print."""


class Config(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    spec_globs: tuple[str, ...] = ("docs/specs/**", "docs/adr/**", "**/REQUIREMENTS.md")


def load_config(text: str | None) -> Config:
    if text is None:
        return Config()
    try:
        return Config.model_validate(tomllib.loads(text))
    except (tomllib.TOMLDecodeError, ValidationError) as error:
        raise ConfigError(f".bylaw.toml on the base branch is invalid: {error}") from error

"""Builds the ReviewContext every reviewer, built-in or host model, works from."""

from collections.abc import Sequence
from pathlib import PurePosixPath

from bylaw.config import load_config
from bylaw.editorconfig import EditorConfigResolver
from bylaw.editorconfig_checks import check
from bylaw.model import Finding, ReviewContext
from bylaw.requirements import collect_requirements
from bylaw.rules import RULE_PATHS, collect_rules
from bylaw.source import RepoSource

LOCKFILES = frozenset(
    {
        "uv.lock",
        "poetry.lock",
        "Pipfile.lock",
        "package-lock.json",
        "yarn.lock",
        "pnpm-lock.yaml",
        "bun.lockb",
        "Cargo.lock",
        "go.sum",
        "composer.lock",
        "Gemfile.lock",
        "packages.lock.json",
    }
)
VENDOR_DIRS = frozenset({"vendor", "node_modules", "third_party"})
_GENERATED_ATTRIBUTES = frozenset(
    {"linguist-generated", "linguist-generated=true", "linguist-vendored", "linguist-vendored=true"}
)


def generated_patterns(gitattributes: str | None) -> tuple[str, ...]:
    if gitattributes is None:
        return ()
    patterns: list[str] = []
    for line in gitattributes.splitlines():
        parts = line.split()
        if len(parts) < 2 or parts[0].startswith("#"):  # noqa: PLR2004 - a pattern and at least one attribute
            continue
        if _GENERATED_ATTRIBUTES.intersection(parts[1:]):
            pattern = parts[0]
            patterns.append(pattern.removeprefix("/") if "/" in pattern else f"**/{pattern}")
    return tuple(patterns)


def is_skipped(path: str, patterns: Sequence[str]) -> bool:
    pure = PurePosixPath(path)
    return (
        pure.name in LOCKFILES
        or not VENDOR_DIRS.isdisjoint(pure.parts[:-1])
        or any(pure.full_match(pattern) for pattern in patterns)
    )


def build_context(source: RepoSource) -> ReviewContext:
    info = source.info()
    config = load_config(source.read_base(".bylaw.toml"))
    patterns = generated_patterns(source.read_base(".gitattributes"))
    all_files = source.changed_files()
    files = tuple(f for f in all_files if not is_skipped(f.path, patterns))
    notes: list[str] = []
    if skipped := len(all_files) - len(files):
        notes.append(f"Skipped {skipped} lock, vendored or generated file(s).")

    resolver = EditorConfigResolver(source.read_base)
    findings: list[Finding] = []
    for file in files:
        if file.status == "removed":
            continue
        if file.patch_omitted:
            notes.append(f"{file.path}: no patch available (binary or too large), not reviewed.")
            continue
        findings.extend(check(file, resolver.properties(file.path)))

    changed_rules = sorted(
        f.path for f in files if f.path in RULE_PATHS or PurePosixPath(f.path).name == ".editorconfig"
    )
    if changed_rules:
        notes.append(
            f"This change edits {', '.join(changed_rules)}; it is reviewed against the base branch "
            "versions (ADR 0004)."
        )

    requirements, requirement_notes = collect_requirements(source, info, files, config.spec_globs)
    return ReviewContext(
        base_sha=info.base_sha,
        head_sha=info.head_sha,
        title=info.title,
        files=files,
        rules=collect_rules(files, source.read_base, resolver.files_read),
        requirements=requirements,
        findings=tuple(findings),
        notes=(*notes, *requirement_notes),
    )
```

```python
"""Command line entry point."""

import argparse
import os
import sys
from collections.abc import Sequence
from importlib.metadata import version
from pathlib import Path

from bylaw.config import ConfigError
from bylaw.context import build_context
from bylaw.github import GitHubClient, GitHubError, GitHubSource
from bylaw.local_git import LocalGitSource
from bylaw.model import ReviewContext
from bylaw.source import SourceError


def _parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="bylaw",
        description="Review pull requests against your repository's own rules and requirements.",
    )
    parser.add_argument("--version", action="version", version=f"bylaw {version('bylaw')}")
    commands = parser.add_subparsers(dest="command", required=True)

    context = commands.add_parser("context", help="print the review context as JSON")
    target = context.add_mutually_exclusive_group(required=True)
    target.add_argument("--pr", type=int, help="pull request number, read through the GitHub API")
    target.add_argument("--base", help="review committed changes from this ref to HEAD in a local repository")
    context.add_argument("--repo", help="owner/name; defaults to GITHUB_REPOSITORY in --pr mode")
    context.add_argument("--path", default=".", help="local repository directory for --base (default: .)")
    return parser


def main(argv: Sequence[str] | None = None) -> int:
    args = _parser().parse_args(argv)
    try:
        context = _context(args)
    except (SourceError, GitHubError, ConfigError) as error:
        print(f"bylaw: {error}", file=sys.stderr)
        return 2
    # Bytes, not text: a Windows console defaults to cp1252 and cannot print every character in a diff.
    sys.stdout.buffer.write(context.model_dump_json(indent=2).encode("utf-8") + b"\n")
    sys.stdout.flush()
    return 0


def _context(args: argparse.Namespace) -> ReviewContext:
    if args.pr is None:
        return build_context(LocalGitSource(Path(args.path), args.base, args.repo))
    repo = args.repo or os.environ.get("GITHUB_REPOSITORY")
    token = os.environ.get("GITHUB_TOKEN") or os.environ.get("GH_TOKEN")
    if not token:
        raise SourceError("GITHUB_TOKEN or GH_TOKEN is required with --pr")
    if not repo:
        raise SourceError("--repo or GITHUB_REPOSITORY is required with --pr")
    api_url = os.environ.get("GITHUB_API_URL", "https://api.github.com")
    with GitHubClient(token, api_url, os.environ.get("GITHUB_GRAPHQL_URL")) as client:
        return build_context(GitHubSource(client, repo, args.pr))
```
