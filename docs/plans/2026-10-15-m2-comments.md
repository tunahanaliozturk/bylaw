# M2: findings, validator and comments, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a reviewer's `ReviewResult` (findings, acceptance criteria results, scope creep) is validated against the `ReviewContext` and published to a pull request as one review with inline comments plus one summary comment, and a second run on a new commit posts nothing twice and resolves fixed threads.

**Architecture:** `validate.py` drops what the context cannot back. `plan.py` is pure: fingerprints, grouping, threshold and cap, and the reconciliation of current findings with the review threads already on the pull request. `render.py` turns a plan into Markdown and reads the hidden state back. `github.py` gains the calls that read threads and write comments. `publish.py` glues them; the CLI gains `validate` and `post`.

**Tech Stack:** as M1. No new dependencies.

**Spec:** `docs/design.md` (Finding, Validator, Comments), ADR 0005, and two new ADRs written in this plan: 0007 (issue references stay in the repository) and 0008 (only trusted authors' comments carry bylaw state).

## Global Constraints

- Everything from the M1 plan's Global Constraints still holds.
- bylaw never approves or requests changes; reviews use `event: "COMMENT"`.
- Default severity threshold `medium`, default cap 15 inline comments per run, both configurable in `.bylaw.toml` (base branch).
- Text from the pull request, its issues and its comments is untrusted. A comment counts as bylaw's own, or as a maintainer's `bylaw: ignore`, only when its author is a bot or has the `OWNER`, `MEMBER` or `COLLABORATOR` association (ADR 0008).
- A GitHub comment body is at most 65,536 characters; the summary must fit with its state intact.
- Code blocks in this plan are preceded by `File: <path>` (create or replace) or `Append to: <path>`.

## Review Focus

1. A pull request author plants a comment containing `<!-- bylaw:fp=... -->` or `<!-- bylaw:summary -->` to suppress a finding or forge state: it must be ignored. Tests in Task 3 and Task 5.
2. A model returns a finding on a context line or a removed line: GitHub would reject the whole review with 422, so the validator drops it first. Test in Task 2.
3. A suggestion that itself contains a triple backtick: the suggestion fence must not break. Test in Task 4.
4. A summary that would exceed 65,536 characters: it is trimmed and the state still parses. Test in Task 4.
5. An issue reference to another repository (`fixes otherorg/private#1`) under a personal token: its text must not reach the summary unless that repository is allow-listed. Test in Task 1.

"""Optional .bylaw.toml, always read from the base branch so a change cannot loosen its own review."""

import tomllib

from pydantic import BaseModel, ConfigDict, Field, ValidationError

from bylaw.model import Severity


class ConfigError(Exception):
    """The configuration file is invalid. The message is safe to print."""


class Config(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    spec_globs: tuple[str, ...] = ("docs/specs/**", "docs/adr/**", "**/REQUIREMENTS.md")
    severity_threshold: Severity = Severity.MEDIUM
    max_comments: int = Field(default=15, ge=0, le=50)
    issue_repos: tuple[str, ...] = ()


def load_config(text: str | None) -> Config:
    if text is None:
        return Config()
    try:
        return Config.model_validate(tomllib.loads(text))
    except (tomllib.TOMLDecodeError, ValidationError) as error:
        raise ConfigError(f".bylaw.toml on the base branch is invalid: {error}") from error
```

def collect_requirements(
    source: RepoSource,
    info: ChangeInfo,
    changed: Sequence[ChangedFile],
    spec_globs: Sequence[str],
    issue_repos: Sequence[str],
) -> tuple[tuple[Requirement, ...], tuple[str, ...]]:
    requirements: list[Requirement] = []
    notes: list[str] = []
    allowed = {repo.lower() for repo in issue_repos}
    if source.repo is not None:
        allowed.add(source.repo.lower())
    keyword_refs = parse_issue_refs([info.body, *info.commit_messages], source.repo)
    for ref in dict.fromkeys([*source.closing_issue_refs(), *keyword_refs]):
        label = ref.label(source.repo)
        if f"{ref.owner}/{ref.repo}" not in allowed:
            # ADR 0007: issue text ends up in a public comment, so another repository needs an opt-in.
            notes.append(f"{label} is in another repository; list it under issue_repos in .bylaw.toml to use it.")
            continue
        issue = source.read_issue(ref)
        if issue is None:
            notes.append(f"Could not read {label}; it is left out of the requirement check.")
            continue
        requirements.append(_requirement(label, issue.title, issue.body))
    for path in spec_paths(changed, info.body, spec_globs, source.repo):
        text = source.read_head(path)
        if text is None:
            notes.append(f"Linked spec {path} does not exist at the head commit.")
            continue
        requirements.append(_requirement(path, _title(text, path), text))
    notes.extend(f"{r.source} has no structured acceptance criteria." for r in requirements if not r.criteria)
    return tuple(requirements), tuple(notes)

File: `docs/adr/0007-issue-references-stay-in-the-repository.md`

```markdown
# 0007: Issue references stay in the repository unless allow-listed

Status: Accepted, 2026-10-15

## Context

A pull request can name any issue with a closing keyword, including one in another repository
(`fixes otherorg/private#1`). From M2 on, the text of linked issues reaches a comment on the pull
request. With the default `GITHUB_TOKEN` bylaw cannot read other private repositories, but with a
personal token, or under `pull_request_target`, a pull request author could pull a private issue into a
public comment. The M1 review raised this and it was deferred until something was published.

## Decision

We read only issues in the pull request's own repository, plus repositories listed under `issue_repos`
in the base branch `.bylaw.toml`.

## Consequences

- A pull request cannot make bylaw copy text from a repository the maintainer did not name.
- A skipped reference is reported in the summary notes with the setting that enables it.
- Cost: projects that track work in a separate issues repository must add one line of configuration.

## Alternatives

- **Same owner only.** Lost because an organisation's private repository can still leak into a public
  one. It would win if bylaw only ever ran on private repositories.
- **Allow everything the token can read.** Lost because the token's reach is decided by whoever set up
  the workflow, not by the person reading the comment. It would win if comments were never public.
```

In `docs/design.md`, under "Requirement sources", replace the first bullet with:

```markdown
- **Issues:** closing keywords (`Closes`, `Fixes`, `Resolves`, with `#n` or `owner/repo#n`) in the PR
  body and commit messages, plus GraphQL `closingIssuesReferences`. Issue body only; comments are left
  out in v1. Only the pull request's own repository and repositories listed under `issue_repos` are read
  ([ADR 0007](adr/0007-issue-references-stay-in-the-repository.md)).
```

```python
"""Drops what the review context cannot back up. Runs on every result, whoever produced it."""

from dataclasses import dataclass

from bylaw.model import Category, CriterionResult, Finding, Location, ReviewContext, ReviewResult, ScopeCreep

_NEEDS_EVIDENCE = frozenset({Category.RULE, Category.REQUIREMENT})


@dataclass(frozen=True, slots=True)
class Validated:
    result: ReviewResult
    dropped: tuple[str, ...]


def validate(context: ReviewContext, result: ReviewResult) -> Validated:
    checker = _Checker(context)
    dropped: list[str] = []

    findings: list[Finding] = []
    seen: set[tuple[str, int, int, Category]] = set()
    for finding in result.findings:
        key = (finding.file, finding.line_start, finding.line_end, finding.category)
        problem = checker.finding_problem(finding)
        if problem is None and key in seen:
            problem = "duplicates another finding on the same lines"
        if problem is not None:
            dropped.append(f"{finding.file}:{finding.line_start} {finding.category}: {problem}")
            continue
        seen.add(key)
        findings.append(finding)

    criteria: list[CriterionResult] = []
    assessed: set[str] = set()
    for item in result.criteria:
        if item.criterion not in checker.criteria:
            dropped.append(f"{item.criterion}: no such acceptance criterion")
            continue
        if item.criterion in assessed:
            dropped.append(f"{item.criterion}: duplicate criterion result")
            continue
        assessed.add(item.criterion)
        code = tuple(location for location in item.code if checker.in_change(location))
        tests = tuple(location for location in item.tests if checker.in_change(location))
        if lost := len(item.code) + len(item.tests) - len(code) - len(tests):
            dropped.append(f"{item.criterion}: {lost} location(s) outside the change")
        criteria.append(item.model_copy(update={"code": code, "tests": tests}))

    scope: list[ScopeCreep] = []
    for entry in result.scope_creep:
        if checker.on_added_line(entry.file, entry.line):
            scope.append(entry)
        else:
            dropped.append(f"{entry.file}:{entry.line} scope creep: not an added line")

    validated = ReviewResult(findings=tuple(findings), criteria=tuple(criteria), scope_creep=tuple(scope))
    return Validated(validated, tuple(dropped))


class _Checker:
    def __init__(self, context: ReviewContext) -> None:
        self._added = {
            f.path: frozenset(a.number for a in f.added_lines) for f in context.files if f.status != "removed"
        }
        self._rule_lines = {r.path: len(r.text.splitlines()) for r in context.rules}
        self.criteria = frozenset(f"{r.source}/{c.key}" for r in context.requirements for c in r.criteria)

    def on_added_line(self, file: str, line: int) -> bool:
        return line in self._added.get(file, frozenset())

    def in_change(self, location: Location) -> bool:
        # A test that proves a criterion may sit on an unchanged line of a changed file.
        return location.file in self._added and location.line >= 1

    def finding_problem(self, finding: Finding) -> str | None:
        if finding.file not in self._added:
            return "file is not part of the change"
        if finding.line_start > finding.line_end:
            return "line range is reversed"
        if not (
            self.on_added_line(finding.file, finding.line_start)
            and self.on_added_line(finding.file, finding.line_end)
        ):
            # GitHub rejects the whole review when one comment is off the diff.
            return "lines are not added by this change"
        if finding.evidence is None:
            return "rule and requirement findings need evidence" if finding.category in _NEEDS_EVIDENCE else None
        if self._evidence_exists(finding.evidence):
            return None
        return f"evidence {finding.evidence} cites nothing bylaw collected"

    def _evidence_exists(self, evidence: str) -> bool:
        if evidence in self.criteria:
            return True
        path, separator, line = evidence.rpartition(":")
        return bool(separator) and line.isdigit() and 1 <= int(line) <= self._rule_lines.get(path, 0)
```

def _context(*lines: tuple[int, str]) -> ReviewContext:
    added = tuple(AddedLine(number=n, text=t) for n, t in lines)
    return ReviewContext(
        base_sha="b",
        head_sha="h",
        title="t",

def _finding(line: int = 1, severity: Severity = Severity.HIGH, message: str = "m") -> Finding:
    return Finding(
        file="app.py",
        line_start=line,
        line_end=line,
        category=Category.SECURITY,
        severity=severity,
        message=message,

def _group(fp: str, severity: Severity = Severity.HIGH, line: int = 1) -> Group:
    return Group(finding=_finding(line, severity), fingerprint=fp, others=())


def _ours(fp: str, thread_id: str = "T1", resolved: bool = False, *replies: ThreadComment) -> Thread:
    first = ThreadComment(body=f"text\n<!-- bylaw:fp={fp} -->", trusted=True)
    return Thread(id=thread_id, resolved=resolved, comments=(first, *replies))

"""Decides what to publish: which findings get inline comments and which existing threads change.

Pure functions over data, so every rule about re-runs is unit tested without GitHub.
"""

import hashlib
import re
from collections.abc import Iterable, Mapping, Sequence
from dataclasses import dataclass

from bylaw.model import Finding, ReviewContext, Severity

FINGERPRINT = re.compile(r"<!-- bylaw:fp=([0-9a-f]{16}) -->")
_IGNORE = re.compile(r"^\s*bylaw:\s*ignore\b", re.IGNORECASE | re.MULTILINE)
_RANK = {severity: rank for rank, severity in enumerate(Severity)}


@dataclass(frozen=True, slots=True)
class Group:
    finding: Finding
    fingerprint: str
    others: tuple[Finding, ...]


@dataclass(frozen=True, slots=True)
class ThreadComment:
    body: str
    trusted: bool


@dataclass(frozen=True, slots=True)
class Thread:
    id: str
    resolved: bool
    comments: tuple[ThreadComment, ...]


@dataclass(frozen=True, slots=True)
class State:
    auto_resolved: frozenset[str]


@dataclass(frozen=True, slots=True)
class Plan:
    inline: tuple[Group, ...]
    summary_only: tuple[Group, ...]
    muted: tuple[Group, ...]
    reviewer_resolved: tuple[Group, ...]
    open_threads: tuple[Group, ...]
    resolve: tuple[str, ...]
    unresolve: tuple[str, ...]
    state: State


def added_text(context: ReviewContext) -> dict[str, dict[int, str]]:
    return {f.path: {a.number: a.text for a in f.added_lines} for f in context.files}


def fingerprint(added: Mapping[str, Mapping[int, str]], finding: Finding) -> str:
    """Hash of what the finding is about, not where it is, so moving code does not repost it."""
    lines = added.get(finding.file, {})
    snippet = " ".join(
        " ".join(lines.get(number, "").split()) for number in range(finding.line_start, finding.line_end + 1)
    )
    raw = "\0".join((finding.file, finding.category, finding.evidence or "", snippet))
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()[:16]


def group_findings(findings: Iterable[Finding], added: Mapping[str, Mapping[int, str]]) -> tuple[Group, ...]:
    grouped: dict[tuple[str, str, str], list[Finding]] = {}
    for finding in findings:
        grouped.setdefault((finding.category, finding.evidence or "", finding.message), []).append(finding)
    return tuple(
        Group(finding=members[0], fingerprint=fingerprint(added, members[0]), others=tuple(members[1:]))
        for members in grouped.values()
    )


def make_plan(
    groups: Sequence[Group],
    threads: Sequence[Thread],
    state: State,
    threshold: Severity,
    cap: int,
) -> Plan:
    ours: dict[str, Thread] = {}
    for thread in threads:
        # ADR 0008: a fingerprint counts only in a comment bylaw or a maintainer could have written.
        if thread.comments and thread.comments[0].trusted and (match := FINGERPRINT.search(thread.comments[0].body)):
            ours.setdefault(match[1], thread)

    current = {group.fingerprint for group in groups}
    fixed = [(fp, thread) for fp, thread in ours.items() if fp not in current and not thread.resolved]
    auto_resolved = set(state.auto_resolved) | {fp for fp, _ in fixed}

    inline: list[Group] = []
    summary_only: list[Group] = []
    muted: list[Group] = []
    reviewer_resolved: list[Group] = []
    open_threads: list[Group] = []
    unresolve: list[str] = []
    for group in sorted(groups, key=_order):
        thread = ours.get(group.fingerprint)
        if thread is None:
            if _RANK[group.finding.severity] > _RANK[threshold] or len(inline) >= cap:
                summary_only.append(group)
            else:
                inline.append(group)
        elif any(reply.trusted and _IGNORE.search(reply.body) for reply in thread.comments[1:]):
            muted.append(group)
        elif thread.resolved and group.fingerprint in auto_resolved:
            unresolve.append(thread.id)
            auto_resolved.discard(group.fingerprint)
            open_threads.append(group)
        elif thread.resolved:
            reviewer_resolved.append(group)
        else:
            open_threads.append(group)

    return Plan(
        inline=tuple(inline),
        summary_only=tuple(summary_only),
        muted=tuple(muted),
        reviewer_resolved=tuple(reviewer_resolved),
        open_threads=tuple(open_threads),
        resolve=tuple(thread.id for _, thread in fixed),
        unresolve=tuple(unresolve),
        state=State(auto_resolved=frozenset(auto_resolved & ours.keys())),
    )


def _order(group: Group) -> tuple[int, str, int]:
    return _RANK[group.finding.severity], group.finding.file, group.finding.line_start
```

```python
"""Markdown for the inline comments and the summary, and the hidden state the summary carries."""

import json
import re
from collections import Counter
from collections.abc import Iterable

from bylaw.model import CriterionResult, Location, ReviewContext, ReviewResult, Severity
from bylaw.plan import Group, Plan, State

SUMMARY_MARKER = "<!-- bylaw:summary -->"
MAX_BODY = 65_536
_STATE = re.compile(r"<!-- bylaw:state (\{.*?\}) -->", re.DOTALL)
_MAX_STATE_ENTRIES = 1000  # ponytail: about 20 KB of hashes; older entries drop off first.
_MAX_PLACES = 5
_TRIMMED = "\n\n_Summary trimmed to fit GitHub's comment size limit._"
_STATUS = {"met": "met", "partial": "partial", "missing": "missing"}


def inline_body(group: Group) -> str:
    finding = group.finding
    parts = [f"**{finding.category} · {finding.severity}** {finding.message}"]
    if finding.evidence:
        parts.append(f"Evidence: `{finding.evidence}`")
    if finding.suggestion is not None:
        fence = "````" if "```" in finding.suggestion else "```"
        parts.append(f"{fence}suggestion\n{finding.suggestion}\n{fence}")
    if group.others:
        places = ", ".join(f"`{other.file}:{other.line_start}`" for other in group.others[:_MAX_PLACES])
        more = f" and {len(group.others) - _MAX_PLACES} more" if len(group.others) > _MAX_PLACES else ""
        parts.append(f"Also at {places}{more}.")
    parts.append(f"<!-- bylaw:fp={group.fingerprint} -->")
    return "\n\n".join(parts)


def review_body(plan: Plan) -> str:
    count = len(plan.inline)
    return f"bylaw left {count} new comment{'s' if count != 1 else ''}. The summary comment has the full picture."


def summary_body(context: ReviewContext, result: ReviewResult, plan: Plan) -> str:
    current = [*plan.inline, *plan.open_threads, *plan.summary_only, *plan.reviewer_resolved]
    sections = [
        SUMMARY_MARKER,
        "## bylaw review",
        _headline(context, plan, current),
        _requirements(context, result),
        _scope_creep(result),
        _details("Other findings", plan.summary_only),
        _details("Resolved by a reviewer but still present", plan.reviewer_resolved),
        _details("Muted with `bylaw: ignore`", plan.muted),
        _rule_sources(context),
        _notes(context),
    ]
    body = "\n\n".join(section for section in sections if section)
    entries = sorted(plan.state.auto_resolved)[-_MAX_STATE_ENTRIES:]
    state = "\n\n<!-- bylaw:state " + json.dumps({"auto_resolved": entries}) + " -->"
    room = MAX_BODY - len(state)
    if len(body) > room:
        body = body[: room - len(_TRIMMED)] + _TRIMMED
    return body + state


def read_state(body: str) -> State:
    """ADR 0005: unreadable state counts as empty, which is noisy but never loses a finding."""
    match = _STATE.search(body)
    if match is None:
        return State(auto_resolved=frozenset())
    try:
        raw = json.loads(match[1])
    except ValueError:
        return State(auto_resolved=frozenset())
    entries = raw.get("auto_resolved", []) if isinstance(raw, dict) else []
    return State(auto_resolved=frozenset(e for e in entries if isinstance(e, str)))


def _headline(context: ReviewContext, plan: Plan, current: list[Group]) -> str:
    counts = Counter(group.finding.severity for group in current)
    by_severity = ", ".join(f"{counts[s]} {s}" for s in Severity if counts[s]) or "no findings"
    new = len(plan.inline)
    return (
        f"Reviewed `{context.head_sha[:7]}` against `{context.base_sha[:7]}`: {by_severity}. "
        f"{new} new inline comment{'s' if new != 1 else ''} this run, {len(plan.resolve)} thread(s) resolved."
    )


def _requirements(context: ReviewContext, result: ReviewResult) -> str:
    if not context.requirements:
        return "### Requirements\n\nNo linked issue or spec was found."
    results = {item.criterion: item for item in result.criteria}
    rows = ["| Criterion | Status | Code | Tests |", "| --- | --- | --- | --- |"]
    for requirement in context.requirements:
        for criterion in requirement.criteria:
            key = f"{requirement.source}/{criterion.key}"
            item: CriterionResult | None = results.get(key)
            status = _STATUS[item.status] if item else "not assessed"
            code = _locations(item.code) if item else ""
            tests = _locations(item.tests) if item else ""
            rows.append(f"| `{key}` {_cell(criterion.text)} | {status} | {code} | {tests} |")
    return "### Requirements\n\n" + "\n".join(rows)


def _scope_creep(result: ReviewResult) -> str:
    if not result.scope_creep:
        return ""
    lines = [f"- `{entry.file}:{entry.line}` {entry.message}" for entry in result.scope_creep]
    return "### Scope creep\n\n" + "\n".join(lines)


def _details(title: str, groups: Iterable[Group]) -> str:
    items = [
        f"- **{g.finding.category} · {g.finding.severity}** `{g.finding.file}:{g.finding.line_start}` "
        f"{g.finding.message}" + (f" ({g.finding.evidence})" if g.finding.evidence else "")
        for g in groups
    ]
    if not items:
        return ""
    return f"<details><summary>{title} ({len(items)})</summary>\n\n" + "\n".join(items) + "\n\n</details>"


def _rule_sources(context: ReviewContext) -> str:
    if not context.rules:
        return ""
    paths = "\n".join(f"- `{rule.path}`" for rule in context.rules)
    return f"<details><summary>Rule sources ({len(context.rules)})</summary>\n\n{paths}\n\n</details>"


def _notes(context: ReviewContext) -> str:
    if not context.notes:
        return ""
    return "### Notes\n\n" + "\n".join(f"- {note}" for note in context.notes)


def _locations(locations: Iterable[Location]) -> str:
    return ", ".join(f"`{location.file}:{location.line}`" for location in locations)


def _cell(text: str) -> str:
    flat = " ".join(text.split()).replace("|", "\\|")
    return flat if len(flat) <= 80 else flat[:77] + "..."
```

                    for c in node.comments.nodes
                )
                threads.append(Thread(id=node.id, resolved=node.is_resolved, comments=comments))
            if not pull.review_threads.page_info.has_next_page:
                return threads
            after = pull.review_threads.page_info.end_cursor

            batch = _ISSUE_COMMENTS.validate_python(self._get(f"/repos/{repo}/issues/{number}/comments", params).json())

```markdown
# 0008: Only trusted authors' comments carry bylaw state

Status: Accepted, 2026-10-15. Refines 0005.

## Context

bylaw finds its own inline comments by a fingerprint marker and its summary by a summary marker, and it
keeps re-run state in the summary. Fingerprints are deterministic, so anyone who can comment on a pull
request, including its author, could post a comment with the marker of a security finding and make
bylaw believe it had already reported it, or post a fake summary with forged state. ADR 0005 also let a
resolved thread mute its finding, and a pull request author can resolve threads on their own pull
request.

## Decision

We treat a comment as bylaw's own, or as a maintainer's `bylaw: ignore`, only when its author is a bot or
has the `OWNER`, `MEMBER` or `COLLABORATOR` association, and a resolved thread no longer mutes a finding;
only `bylaw: ignore` from a trusted author does.

## Consequences

- A pull request author cannot hide a finding by planting markers or by resolving the thread.
- A finding whose thread a reviewer resolved while the problem is still present stays resolved but is
  listed in the summary under "Resolved by a reviewer but still present", so nothing disappears quietly.
- bylaw tracks only the threads it resolved itself (`auto_resolved`), so a finding that comes back
  reopens its thread.
- Cost: any bot can write a summary marker. A repository that runs a hostile bot has bigger problems,
  but the check is by account type, not by identity.

## Alternatives

- **Match the exact bot login.** Lost because the identity differs between `GITHUB_TOKEN`, a GitHub App
  and a personal token, and an installation token cannot ask who it is. It would win if bylaw shipped
  as a GitHub App with a fixed identity.
- **Keep resolve-to-mute from ADR 0005.** Lost because it lets the author silence their own review.
```

```markdown
- **Re-runs.** An existing fingerprint is not posted again. A fingerprint that disappeared means the issue
  was fixed and bylaw resolves its thread; if the problem comes back, bylaw reopens it. A maintainer
  mutes a finding by replying `bylaw: ignore`. Only comments from bots and from people with write access
  count ([ADR 0008](adr/0008-trusted-authors-carry-state.md)). State lives as hidden JSON in the summary
  comment ([ADR 0005](adr/0005-state-in-summary-comment.md)).
```

"""Publishes a validated review: one review with the new inline comments, thread changes, the summary."""

from collections.abc import Sequence
from typing import Protocol

from bylaw.config import Config
from bylaw.github import ReviewComment, SummaryComment
from bylaw.model import ReviewContext, ReviewResult
from bylaw.plan import Plan, State, Thread, added_text, group_findings, make_plan
from bylaw.render import inline_body, read_state, review_body, summary_body


class Publisher(Protocol):
    def review_threads(self, repo: str, number: int) -> list[Thread]: ...

    def summary_comment(self, repo: str, number: int) -> SummaryComment | None: ...

    def create_review(
        self, repo: str, number: int, commit_id: str, body: str, comments: Sequence[ReviewComment]
    ) -> None: ...

    def upsert_summary(self, repo: str, number: int, comment_id: int | None, body: str) -> None: ...

    def set_thread_resolved(self, thread_id: str, *, resolved: bool) -> None: ...


def publish(
    client: Publisher, repo: str, number: int, context: ReviewContext, result: ReviewResult, config: Config
) -> Plan:
    summary = client.summary_comment(repo, number)
    state = read_state(summary.body) if summary else State(auto_resolved=frozenset())
    plan = _plan(context, result, config, client.review_threads(repo, number), state)
    if plan.inline:
        comments = [
            ReviewComment(g.finding.file, g.finding.line_end, g.finding.line_start, inline_body(g))
            for g in plan.inline
        ]
        client.create_review(repo, number, context.head_sha, review_body(plan), comments)
    for thread_id in plan.resolve:
        client.set_thread_resolved(thread_id, resolved=True)
    for thread_id in plan.unresolve:
        client.set_thread_resolved(thread_id, resolved=False)
    client.upsert_summary(repo, number, summary.id if summary else None, summary_body(context, result, plan))
    return plan


def preview(context: ReviewContext, result: ReviewResult, config: Config) -> str:
    """What a first run would post, for a terminal with no pull request."""
    plan = _plan(context, result, config, (), State(auto_resolved=frozenset()))
    comments = [
        f"---\n`{g.finding.file}:{g.finding.line_start}`\n\n{inline_body(g)}" for g in plan.inline
    ]
    return "\n\n".join([summary_body(context, result, plan), *comments])


def _plan(
    context: ReviewContext, result: ReviewResult, config: Config, threads: Sequence[Thread], state: State
) -> Plan:
    groups = group_findings(result.findings, added_text(context))
    return make_plan(groups, threads, state, config.severity_threshold, config.max_comments)
```

def main(argv: Sequence[str] | None = None) -> int:
    args = _parser().parse_args(argv)
    try:
        if args.command == "context":
            _write(_context(args).model_dump_json(indent=2))
        elif args.command == "validate":
            checked = _validated(args)
            payload = {"result": checked.result.model_dump(mode="json"), "dropped": list(checked.dropped)}
            _write(json.dumps(payload, indent=2, ensure_ascii=False))
        else:
            _post(args)
    except (SourceError, GitHubError, ConfigError, OSError, ValueError) as error:
        print(f"bylaw: {error}", file=sys.stderr)
        return 2
    return 0


def _write(text: str) -> None:
    # Bytes, not text: a Windows console defaults to cp1252 and cannot print every character in a diff.
    sys.stdout.buffer.write(text.encode("utf-8") + b"\n")
    sys.stdout.flush()


def _validated(args: argparse.Namespace) -> Validated:
    context = ReviewContext.model_validate_json(Path(args.context).read_text(encoding="utf-8"))
    result = (
        ReviewResult.model_validate_json(Path(args.result).read_text(encoding="utf-8"))
        if args.result
        else ReviewResult()
    )
    merged = result.model_copy(update={"findings": (*context.findings, *result.findings)})
    return validate(context, merged)


def _post(args: argparse.Namespace) -> None:
    context = ReviewContext.model_validate_json(Path(args.context).read_text(encoding="utf-8"))
    checked = _validated(args)
    for reason in checked.dropped:
        print(f"bylaw: dropped {reason}", file=sys.stderr)
    if args.dry_run:
        _write(preview(context, checked.result, Config()))
        return
    repo, token = _repo_and_token(args.repo)
    api_url = os.environ.get("GITHUB_API_URL", "https://api.github.com")
    with GitHubClient(token, api_url, os.environ.get("GITHUB_GRAPHQL_URL")) as client:
        config = load_config(GitHubSource(client, repo, args.pr).read_base(".bylaw.toml"))
        plan = publish(client, repo, args.pr, context, checked.result, config)
    print(
        f"bylaw: posted {len(plan.inline)} comment(s), resolved {len(plan.resolve)}, "
        f"reopened {len(plan.unresolve)} thread(s), updated the summary.",
        file=sys.stderr,
    )


def _repo_and_token(repo_arg: str | None) -> tuple[str, str]:
    repo = repo_arg or os.environ.get("GITHUB_REPOSITORY")
    token = os.environ.get("GITHUB_TOKEN") or os.environ.get("GH_TOKEN")
    if not token:
        raise SourceError("GITHUB_TOKEN or GH_TOKEN is required with --pr")
    if not repo:
        raise SourceError("--repo or GITHUB_REPOSITORY is required with --pr")
    return repo, token
